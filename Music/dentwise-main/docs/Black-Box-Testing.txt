Black Box Testing - DentWise Application
1. Testing Approach
This document outlines the black-box testing strategy using: - Equivalence Partitioning
(EP): Dividing input data into valid and invalid partitions - Boundary Value Analysis (BVA):
Testing at the edges of input ranges
